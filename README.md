
# Student Dropout Prediction

## Project Overview
Developed a Machine Learning model to predict
student academic outcomes: Graduate, Dropout,
and Enrolled.

## Dataset
- 4,424 student records
- 34 features
- Demographic, socioeconomic and academic data

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Algorithms
- Logistic Regression
- KNN
- SVM
- Decision Tree

## Model Performance
- Test Accuracy: 74.7%
- Weighted F1-Score: 0.74
- Weighted ROC-AUC: 0.88

## Project Workflow
1. Data Collection
2. Exploratory Data Analysis
3. Data Preprocessing
4. Feature Engineering
5. Model Training
6. Hyperparameter Tuning
7. Model Evaluation

## How to Run
pip install -r requirements.txt

Open the notebook using Jupyter Notebook.
